# Apple Home Scanner

Home-Assistant-App zum Scannen von Apple-Home-, HomeKit- und Matter-QR-Codes:

- erkennt `X-HM://…`, 8-stellige HomeKit-Codes, `MT:…` und 11-/21-stellige Matter-Codes
- wandelt Matter-QR-Codes in den manuellen Matter-Code um
- fügt HomeKit-Geräte (HomeKit Controller) und Matter-Geräte (Matter-Integration) direkt zu Home Assistant hinzu
