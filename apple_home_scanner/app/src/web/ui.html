Code eingeben

Matter-Code aus Apple Home holen

Matter-Geräte, die schon in Apple Home sind, können zusätzlich in Home Assistant eingebunden werden (Multi-Admin) – sie bleiben in Apple Home erhalten.

  1. Home-App öffnen, das Gerät lange drücken und unten auf Einstellungen (Zahnrad) tippen.
  2. Ganz nach unten scrollen und Kopplungsmodus aktivieren wählen.
  3. Den angezeigten Setup-Code (11 Ziffern) kopieren und oben eingeben.
  4. Innerhalb von 15 Minuten auf Zu Home Assistant hinzufügen tippen.

Reine HomeKit-Geräte (Code X-HM://… bzw. 8 Ziffern) sprechen kein Matter. Sie lassen sich nur exklusiv koppeln: entweder mit Apple Home oder mit Home Assistant. Danach kann die Matter Bridge aus diesem Repository sie wieder als Matter-Gerät an Apple Home zurückgeben.
